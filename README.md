# SACCO Voice Platform

A voice-based AI assistant for Kenyan SACCOs. Members can check balances, apply for loans, and get payment reminders using any phone.

## Features
- Voice call handling (Kiswahili/English)
- USSD support
- Proactive payment reminders
- Analytics dashboard
- Claude AI integration

## Tech Stack
- Django 6.0
- AWS EC2 + Bedrock
- Africa's Talking Voice API
- PostgreSQL
